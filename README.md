# Statecraft: Israel, opening film materials

Recorded by an agent. This repository holds the work so far on the opening film for
[Statecraft: Israel](https://github.com/eyalgolan/statecraft-israel). It has no code. It goes with
[issue 2953](https://github.com/eyalgolan/statecraft-israel/issues/2953), which asks for a new opening film.

The owner judged this work not good enough. In their words, it "resulted in an ai slop". It is here so a
contributor can see what was tried, reuse what helps and avoid what did not work.

## What is here

- `docs/SCRIPT-v9-EN.md`: the latest script idea (7 Nov 2026), English, about 70 seconds.
- `docs/SCRIPT-v7.md`: the earlier 80-second script with a shot table. The `V` clips were made for it.
- `docs/FINAL-PROMPTS-v5.md`: the exact image-to-video prompts for the `C` clips (8 Nov 2026). Paths in
  it point to reference photos that are not in this repository.
- `docs/CUT-REPORT-colour-v1.md`: the cut list of the newest cut, `cut-colour-v1.mp4`.

## Videos

All 102 videos are assets of the release
[materials-2026-11-08](https://github.com/eyalgolan/statecraft-opening-film/releases/tag/materials-2026-11-08).
Every clip is AI-generated. None has a voice-over.

| Prefix | What it is |
|---|---|
| `cut-` | Assembled cuts. `cut-colour-v1.mp4` (67 s, 8 Nov) is the newest. `cut-thriller-v1.mp4` (91 s) is the thriller attempt. `cut-opening-film-v1.mp4` (75 s) is the SCRIPT-v7 cut, and `-game` files are smaller encodes of the same cuts. `cut-roughcut-v9.mp4` and `cut-preview-r9.mp4` are rough cuts of SCRIPT-v9. |
| `clip-C*` | Image-to-video clips for the colour cut (`raw` = as generated, `retake1` = second try). |
| `clip-A1*`, `clip-B1*` | The bombing of Tel Aviv shots (`raw` = as generated, `cut` = trimmed, `comp` = colour transferred, as used in the colour cut). |
| `clip-V*` | Clips for SCRIPT-v7 (6 Nov). |
| `clip-N*` | New shots for SCRIPT-v8 (7 Nov). `local` = made with local tools. |
| `clip-DESK*` | The desk anchor shot. |
| `editclip-` | Trimmed pieces of the clips above, as used in the cuts. |
